How do I start using Tavily and get an API key?

Sign up for a free account and get your API key from the dashboard, this key authenticates all API requests.

Install the SDK (e.g., Python or JavaScript) and plug in your API key to start making calls.You start with 1,000 free API credits per month with no credit card required.

When do my monthly API credits reset?

Your API credits reset on the first day of each month, regardless of the billing date. This ensures you start each month with a clean slate of credits to use for your searches.

What is an API credit and how is usage calculated?

API credits are consumed based on the type of request you make (such as search, extract, or crawl). More advanced or higher-volume requests use more credits. Full usage details are available in the documentation.

What happens if I run out of credits?

If you exhaust your monthly credits, requests will stop until your credits reset or you upgrade to a paid plan. Paid plans provide higher monthly limits and uninterrupted usage.
