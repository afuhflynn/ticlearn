# Rate Limits

Last updated 8 months ago

Tavily offers two types of rate limits, each specific to the environment associated with your API key. These are the **Development** and **Production** environments. Each environment has its own set of rate limits that dictate how many requests can be made per minute.

#### **Development Environment**

- **Requests per minute (RPM)**: **100**

- The Development environment is designed for testing and development purposes. It allows up to 100 requests per minute, which is ideal for experimenting with API calls and integrating features without impacting your production environment.


#### **Production Environment**

- **Requests per minute (RPM)**: **1,000**

- The Production environment is intended for live applications and services. It offers a higher rate limit of 1,000 requests per minute, allowing you to scale your usage as your application goes live and experiences increased traffic.


## **Crawl Endpoint Rate Limits**

The crawl endpoint has a separate rate limit that applies to both development and production keys:

|     |     |
| --- | --- |
| Environment | Requests per minute (RPM) |
| `Development` | 100 |
| `Production` | 100 |
